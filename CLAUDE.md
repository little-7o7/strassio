# Strassio — плагин страз для CorelDRAW

Strassio превращает линии и фигуры в CorelDRAW в шаблоны страз: каждая страза — обычный круг нужного диаметра.
Полное техническое задание: **docs/SPEC.md**. Читать перед началом любой новой функции.

## Общение с автором

- Автор проекта пишет по-русски (иногда латиницей). Всегда отвечать по-русски.
- Автор — практик-дизайнер страз, не профессиональный программист. Объяснять просто, без лишнего жаргона.
- Claude НЕ может запустить CorelDRAW. После любых изменений в CorelDRAW-части давать автору короткий
  нумерованный список: что открыть, что нажать, что должно получиться. Просить прислать скриншот или текст ошибки.

## Главные правила

1. Результат плагина — только круги в CorelDRAW. Нет растра/фото, каталога камней, расчёта заказа, экспорта
   (DXF и ArtCAM автор делает сам).
2. Вся геометрия живёт в `Strassio.Core` и не знает о CorelDRAW. Любой алгоритм сначала покрывается тестами
   и проверяется через SVG-превью (`tools/Strassio.Preview`), и только потом подключается к CorelDRAW.
3. Маленькие шаги. После каждого рабочего шага — `git commit` с понятным сообщением. Не ломать то, что работает.
   Изменения для автора записывать в `docs/CHANGELOG.md`.
4. Не копировать код, названия, иконки, тексты и внешний вид rStones и других конкурентов.
5. Все тексты интерфейса — только через файлы языков (`lang/ru.json`, `lang/en.json`). Никаких строк в коде.
   Язык меняется без перезапуска CorelDRAW.
6. Внутри всё считается в миллиметрах (`double`). Дюймы — только при отображении и вводе.
7. Минимум сторонних библиотек в аддоне. CorelDRAW сам загружает свои версии DLL, и конфликт версий
   ломает плагин. Если библиотека всё же нужна — встраивать её в свою сборку (ILRepack) или писать своё.
   JSON — через встроенный `DataContractJsonSerializer` или свой простой сериализатор.
8. Секреты (приватный ключ подписи, пароль админки, строки подключения к базе) — только в переменных
   окружения. Никогда не коммитить.

## Совместимость с CorelDRAW

- Цель: **все версии начиная с X7 и все будущие**. X7 — первая версия с современной установкой
  .NET-аддонов через папку `Addons` и XSLT. Старее X7 не поддерживаем.
- X7 и X8 бывают 32-битными → сборка `AnyCPU`. Папка аддона: `<CorelDRAW>\Programs64\Addons\Strassio\`
  (для 32 бит — `Programs\Addons\Strassio\`). Установленные версии искать через реестр.
- Формат `AppUI.xslt` / `UserUI.xslt` для кнопки, панели и докера — изучить на open-source аддонах
  bonus630 на GitHub (они поддерживают X7 и выше). Не угадывать формат, а сверяться с рабочими примерами.
- **Первая задача Этапа 0** — выяснить, работает ли ОДНА DLL на всех версиях:
  собрать против interop самой старой доступной версии с `EmbedInteropTypes=true` и проверить на версии автора.
  Если не работает — сборка отдельной DLL под каждую версию из одного кода (матрица MSBuild по пути к VGCore)
  или позднее связывание (`dynamic`). Решение записать в SPEC.md.
- Путь к CorelDRAW на машине разработчика — в `local.props` (в `.gitignore`), не в общем коде.

## Кнопка запуска

Своя панель инструментов «Strassio» с одной кнопкой-камнем (`assets/icon`). Кнопка открывает и закрывает докер.
Пользователь может перетащить кнопку на любую панель. Дублируется в меню «Окно → Докеры → Strassio».

## Правила работы с API CorelDRAW (скорость и отмена)

- На время операции: `app.Optimization = true; app.EventsEnabled = false;` — строго в `try/finally`,
  в конце вернуть как было и вызвать обновление экрана.
- Каждая операция — одна группа отмены: `doc.BeginCommandGroup("Strassio: ...")` … `doc.EndCommandGroup()`.
  Ctrl+Z отменяет всю операцию целиком.
- На время операции `doc.Unit = cdrMillimeter`, после — восстановить.
- Кривую читать один раз (узлы и контрольные точки Безье), считать всё в Core, обратно только создавать круги
  (`CreateEllipse2`) и группировать. Минимум COM-вызовов внутри циклов.
- Цель по скорости: 10 000 камней создаются без зависания интерфейса; расчёт в Core — доли секунды.

## Сборка и проверка

- Сборка: `dotnet build` (или MSBuild для net48-проекта).
- Тесты ядра: `dotnet test tests/Strassio.Core.Tests`.
- Визуальная проверка: `dotnet run --project tools/Strassio.Preview -- <сценарий>` → SVG в `out/preview/`.
  Обязательные сценарии для углов: звезда, сердце, зигзаг с острыми углами, тугая спираль, S-кривая, буквы.

## Работа на Mac (с 2026-10-05)

Автор работает на MacBook, CorelDRAW проверяет на Windows. Подробно — `docs/РАБОТА-НА-MAC.md`.

- **План и состояние — `docs/ПЛАН.md`.** Читать в начале работы, обновлять после каждого рабочего шага.
- На Mac собираются только кроссплатформенные части: тесты ядра и Preview. Аддон (net48 + WPF), UiShots
  и установщик собирает GitHub Actions (`.github/workflows/build.yml`) после каждого push в master.
  После push проверить запуск: `gh run list --limit 1`, при ошибке — `gh run view <id> --log-failed`.
- Выпуск версии: одинаковая версия в `Strassio.Corel.csproj` и `installer/Strassio.iss`, запись в CHANGELOG,
  текст выпуска в `docs/releases/vX.Y.Z.md` (первая строка `# Strassio X.Y.Z — …`), затем
  `git tag vX.Y.Z && git push origin master vX.Y.Z` — GitHub сам соберёт установщик и выложит пробный выпуск.
- Список проверки для автора начинается с «скачайте Strassio-Setup-X.Y.Z.exe со страницы Releases».
- Репозиторий публичный: коммиты только с адресом `97856162+little-7o7@users.noreply.github.com`.

## Сервер

- На время разработки и бета-теста — Vercel Hobby (бесплатно). Hobby разрешён только для некоммерческого
  использования, поэтому **до первой продажи** сервер переезжает на Vercel Pro или Cloudflare Workers.
- Поэтому вся логика лицензий — в `server/core/` без привязки к Vercel. Платформа — тонкий адаптер.
- База: Postgres (Neon, бесплатный план через маркетплейс Vercel), доступ через `DATABASE_URL`.
