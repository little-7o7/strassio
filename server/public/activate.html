Активация

В CorelDRAW откройте окно «Лицензия» и нажмите «Копировать» рядом с кодом компьютера (или «Открыть сайт активации» — тогда код вставится сам). Здесь введите ключ и получите код активации.

Код активации

Скопируйте его и вставьте в окне «Лицензия» в поле «Код активации», затем нажмите «Активировать». Код подходит только для этого компьютера.
