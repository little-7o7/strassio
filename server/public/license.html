Моя лицензия

Здесь можно посмотреть, на каких компьютерах работает ваш ключ, освободить старый компьютер и получить файл лицензии для компьютера без интернета.

Ключ восстановления выдаётся вместе с ключом. Если потеряли — напишите автору, он выдаст новый.

Код компьютера показан в плагине в окне «Лицензия». «Освободить» считается переносом: переносить можно раз в 7 дней.

Файл лицензии для компьютера без интернета

В плагине откройте окно «Лицензия», нажмите «Копировать» рядом с кодом компьютера и вставьте сюда. Скачанный файл загрузите кнопкой «Файл лицензии…» в том же окне.
