# История изменений Strassio

Здесь простыми словами записывается, что изменилось в каждой версии.

## [не выпущено]
- Создано ТЗ (docs/SPEC.md), правила проекта (CLAUDE.md) и иконка кнопки-камня.
- Этап 0 (черновик, ждёт проверки автором в CorelDRAW):
  - Починены ошибки в заготовке проекта (не совпадало имя файла интеропа; тестовый и
    Preview-проекты были нацелены на несуществующий .NET 10 — переключены на .NET 8).
  - Проверено: все 5 проектов (`Strassio.Core`, `Strassio.Licensing`, `Strassio.Corel`,
    тесты, Preview) собираются одной командой `dotnet build` без ошибок.
  - Добавлен пустой докер Strassio (WPF) с одной тестовой кнопкой «Создать тестовую стразу (ss6)» —
    создаёt один круг диаметром 2,4 мм на активном документе, одной группой отмены (Ctrl+Z).
  - Добавлены `AppUI.xslt` / `UserUI.xslt` — кнопка-камень, своя панель инструментов «Strassio»,
    пункт в меню «Окно → Докеры → Strassio». Формат сверен с открытыми рабочими аддонами bonus630
    для CorelDRAW X7+, подробности и на что смотреть при проверке — в docs/SPEC.md, раздел 18.
  - Значок камня на кнопке пока не подключён (нужна отдельная небольшая задача — компиляция
    ресурса CorelDRAW под иконку). Кнопка пока с подписью «Strassio» без картинки.
  - Проверено автором в реальном CorelDRAW: панель «Strassio», докер открывается вкладкой справа,
    кнопка «Создать тестовую стразу (ss6)» создаёт круг 2,4 мм, отмена одним Ctrl+Z — всё работает.
  - **Этап 0 закрыт.** Дальше — Этап 1 (ядро): модели, таблица камней, стразы по линии L1–L3
    с углами, заливка F1–F5, исправление пересечений, Preview-инструмент, тесты.
