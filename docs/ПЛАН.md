  `/adminpanel` и `/api/admin/*` удалены по слову автора. `ADMIN_PASSWORD` остаётся: его спрашивает хаб для опасных действий.

## Переделка по проверке ECC (2026-11-08)

Плагин ECC (Everything Claude Code) проверил весь проект четырьмя проверяющими. Опасное уже исправлено
(см. CHANGELOG). Ниже — что ECC предлагает переделать; порядок — по важности, выбирает автор.

До продажи:
1. Закрыть репозиторий strassio: он сейчас публичный, проверку лицензии может прочитать каждый.
2. ~~Удалить старую `/adminpanel` и `/api/admin/*`~~ — сделано 2026-11-08, всё в хабе.
3. Установщик: `C:\Strassio` по умолчанию доступна на запись всем пользователям Windows — подменённый
   `unins000.exe` запустится с правами администратора при удалении. Проверить `icacls C:\Strassio`;
   программу — в Program Files, в `C:\Strassio` — только `data`.
4. Цифровая подпись установщика и её проверка в Strassio.Connect перед запуском обновления: сейчас обновление
   защищено только SHA-256 с сервера (утечка `RELEASES_TOKEN` — чужой код на всех компьютерах).
5. Лимиты запросов — в Vercel Firewall (есть в Pro) или в базе, а не в памяти одной функции; отдельный лимит
   на пробные периоды (выдуманными кодами компьютера можно заполнить бесплатную базу Neon).

Лицензия:
6. Офлайн-файлы — со сроком (например, год, с продлением), а не вечные.
7. Отказы сервера (отозван, заблокирован) подписывать, как лицензии; удалять лицензию только по подписанному.
8. Код компьютера, вторая версия: «пустые» UUID плат и ProcessorId не считать признаками (два одинаковых
   самосборных ПК сейчас совпадают). Меняет совпадение для уже активированных — только с переходом.
9. Офлайн-компьютер после одного скачка часов вперёд (сбой батарейки) блокируется навсегда.
10. `client.json` (телефон, почта) — в профиль пользователя, а не в общую `C:\Strassio\data`;
    решить, нужны ли телефон и день рождения в «О программе» (сверка отдаёт их по коду активации).
11. Почта ключа — обязательна при создании ключа, а не «первая введённая на сайте».

Аддон (нужна проверка в CorelDRAW):
12. Докер: подписки на события — симметрично при открытии и закрытии (после перетаскивания докера строка
    лицензии может перестать обновляться).
13. Скорость на 10 000 камней: мотивы читаются с диска на каждый клик по цвету, стразы удаляются по одной,
    «Очистить круги» читает рецепт у каждой стразы.
14. «Повтор» читает свойства уже удалённых камней на шве; «Обновить живые» кладёт группу на активный слой,
    а не на слой старой группы.
15. Ошибка посреди операции оставляет половину изменений — откатывать (`doc.Undo`, проверить на X7)
    и писать журнал `strassio.log` для поддержки.
16. Мелочи: « bit)», «64 bit» и английское сообщение автообновления — в файлы языков; смена палитры — без
    группы отмены.

Сверление:
17. При сохранении сверять место и глубину каждого отверстия, а не только их число (обещано в SPEC 11.1).
18. Импорт настроек — проверять всю таблицу камней и каталог свёрл, а не только первый набор.
19. `G43 H` (коррекция длины сверла) после смены сверла — как вариант формата, если на станке
    несколько свёрл в одном файле.

Тесты и сервер:
20. Проверку файлов языков (одинаковые ключи и `{n}`) и перебор вариантов G-code — в постоянные тесты.
21. Схема базы — отдельной миграцией, а не 25 запросами при каждом холодном старте; поиск в админке —
    без запроса на каждый ключ.
