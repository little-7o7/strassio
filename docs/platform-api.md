# Закрытый API для хаба little_7o7 (`/api/platform`)

Сделан 2026-11-08: админка Strassio переехала в хаб little_7o7 (`little-7o7.vercel.app/admin` → Strassio), старые
`/adminpanel` и `/api/admin/*` удалены в тот же день. Владелец:
«dobav k little_7o7 admin panel xab, i udali adminku ot strassio». Хаб говорит со Strassio так же, как с Sarpo
Business: подписанными запросами, в базу Strassio не ходит. Код: `server/core/platformAuth.ts` (подпись),
`server/core/platform.ts` (адреса), тесты `server/tests/platform.test.ts`.

## Включение

API выключен, пока в Vercel → strassio → Settings → Environment Variables нет обеих переменных:
`PLATFORM_API_KEY` и `PLATFORM_API_SECRET` (каждая не короче 32 знаков, разные). Пару создаёт хаб: Strassio →
Система → Подключение → «Сгенерировать пару». После записи в Vercel — Redeploy. В git ключи не кладём никогда.

Выключен или подпись неверна — на любой адрес ответ `404 {"ok":false,"error":"no_route"}`, как на несуществующий;
база не трогается.

## Подпись запроса

| Заголовок | Что |
| --- | --- |
| `X-Hub-Key` | `PLATFORM_API_KEY` |
| `X-Hub-Time` | время запроса, секунды Unix; дальше 5 минут от часов сервера — 404 |
| `X-Hub-Nonce` | случайная строка 16–64 знака `[A-Za-z0-9_-]`, второй раз — 404 |
| `X-Hub-Signature` | HMAC-SHA256, ключ `PLATFORM_API_SECRET`, hex |

Подписывается строка из пяти строк через `\n`: метод (`GET`/`POST`), путь с запросом (`/api/platform/licenses?q=abc`,
запрос собран через `URLSearchParams`), время, nonce, sha256 тела в hex (у GET — от пустой строки). Тело POST — объект
JSON (`JSON.stringify`), не больше 64 КБ.

Использованные nonce — таблица `platform_nonces` (nonce, до какого времени помнить); устаревшие стираются при каждой
записи. Других изменений в базе нет.

## Пароль для опасного

Заблокировать ключ, удалить ключ, отозвать компьютер, удалить пробный период и опубликовать обновление — только с
паролем админки Strassio в теле: `"adminPassword": "…"` (переменная `ADMIN_PASSWORD` в Vercel; хаб его не хранит).
Решение владельца 2026-11-08. Неверный пароль 10 раз за 15 минут — дальше `429` и для верного.

## Ответы

Успех — `{"ok": true, …}`. Ошибка подписанного запроса — `{"ok": false, "error": "<код>"}`:

| Код | HTTP | Что |
| --- | --- | --- |
| `missing` | 404 | нет такого ключа, заявки, компьютера или пробного периода |
| `bad_request` | 400 | неверные данные (срок, версия, ссылка, SHA-256, код компьютера, состояние заявки) |
| `bad_client` | 400 | неверная почта, Telegram или день рождения клиента |
| `confirm` | 400 | при удалении ключа не совпали последние 4 знака |
| `already_has_key` | 409 | по заявке уже создан ключ (в ответе `serial`) |
| `password_required`, `wrong_password` | 403 | нет пароля админки или он неверный |
| `password_not_set` | 503 | в Vercel нет `ADMIN_PASSWORD` (короче 8 знаков) |
| `too_many_requests` | 429 | слишком много неверных паролей |
| `github` | 502 | «Заполнить из GitHub» не получилось, причина в `details` |

## Просмотр (GET)

| Адрес | Что |
| --- | --- |
| `ping` | проверка ключей: `project: "strassio"`, время |
| `health` | ответ базы и за сколько мс, регион, коммит |
| `summary` | ключи (всего, активных, заблокированных, истёкших, кончаются за 30 дней, бессрочных), компьютеры (активных, проверялись за сутки), пробные (идут, всего), заявки (новых, в работе), что опубликовано в stable и beta, «требует внимания»: ключи, у которых срок кончается за 30 дней, и новые заявки |
| `licenses?q=` | ключи: поиск по ключу, имени, фамилии, телефону (в любом виде: `90 123 45 67`, `+998901234567`), почте, Telegram, заметке; пусто — последние 100 |
| `licenses?all=1` | все ключи (до 20 000) — для выгрузки в Excel |
| `licenses/<ключ>/history` | история ключа из журнала (до 200, новые сверху): кто, что, когда; полные коды компьютеров заменены короткими |
| `clients` | клиенты: один человек (телефон, иначе почта, Telegram или имя) — все его ключи и компьютеры; `birthdays` — дни рождения в этом месяце по Ташкенту |
| `clients/<id>` | карточка клиента (id — 12 знаков из `clients`): контакты, ключи, компьютеры, заявки с сайта, заметки |
| `computers` | все подключённые компьютеры: версия плагина и CorelDRAW, «не обновился» (ниже stable), «давно не открывали» (30 дней и больше при рабочем ключе); счётчики версий |
| `attention` | на что взглянуть: подозрительные ключи (3 и больше компьютеров за 90 дней, с попытками «место занято»), ключи без клиента, один телефон — разные имена, старые заявки, ключи, истёкшие больше полугода назад, пробные без покупки и похожие компьютеры на пробном |
| `licenses/<ключ>` | карточка ключа: состояние (`active`, `blocked`, `expired`), срок и сколько дней осталось, переносы и когда следующий, заметка, клиент, компьютеры (короткий код, полный код, последняя проверка, версии) |
| `requests` | заявки с сайта `/buy`, новые сверху (200) |
| `trials` | пробные периоды: всего, идут, список с днями |
| `updates` | что сейчас получают плагины в stable и beta |
| `release?channel=stable\|beta` | последний выпуск strassio-releases: версия, ссылка, SHA-256 (сервер считает сам), что нового: `notesRu` из раздела «Что нового», `notesEn` из «What's new» (нет раздела — пусто) |
| `audit?limit=` | журнал действий (по умолчанию 200, до 500): кто (`admin`, `hub`, `client`, `site`), что, ключ. Фильтры: `serial`, `who` (`hub` — хаб и старая админка, `client`, `site`), `action` (код действия), `from` и `to` (`ГГГГ-ММ-ДД` по Ташкенту, оба дня включительно) |

## Telegram и утренняя сводка

Бот пишет только владельцу. Переменные Vercel проекта strassio (вносит владелец, в git — никогда):

- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — без них бот молчит, остальное работает;
- `HUB_URL` — адрес хаба для ссылок в сообщениях (по умолчанию `https://little-7o7.vercel.app`);
- `CRON_SECRET` — не короче 16 знаков: без него утренняя сводка выключена.

Сразу: новая заявка с сайта и новая активация ключа на компьютере. Каждое утро в 9:00 по Ташкенту (cron Vercel
`/api/cron/daily`, 04:00 UTC): заявки и активации за сутки, закончившиеся пробные (и сколько без покупки), ключи,
у которых срок кончается через 7 дней и меньше, с телефонами, дни рождения сегодня с готовым поздравлением. Нечего
сказать — сообщения нет. Telegram не ответил — заявка и активация всё равно проходят.
