# Закрытый API для хаба little_7o7 (`/api/platform`)

Сделан 2026-11-08: админка Strassio переехала в хаб little_7o7 (`little-7o7.vercel.app/admin` → Strassio), старые
`/adminpanel` и `/api/admin/*` удалены в тот же день. Владелец:
«dobav k little_7o7 admin panel xab, i udali adminku ot strassio». Хаб говорит со Strassio так же, как с Sarpo
Business: подписанными запросами, в базу Strassio не ходит. Код: `server/core/platformAuth.ts` (подпись),
`server/core/platform.ts` (адреса), тесты `server/tests/platform.test.ts`.

## Включение

API выключен, пока в Vercel → strassio → Settings → Environment Variables нет обеих переменных:
`PLATFORM_API_KEY` и `PLATFORM_API_SECRET` (каждая не короче 32 знаков, разные). Пару создаёт хаб: Strassio →
Система → Подключение → «Сгенерировать пару». После записи в Vercel — Redeploy. В git ключи не кладём никогда.

Выключен или подпись неверна — на любой адрес ответ `404 {"ok":false,"error":"no_route"}`, как на несуществующий;
база не трогается.

## Подпись запроса

| Заголовок | Что |
| --- | --- |
| `X-Hub-Key` | `PLATFORM_API_KEY` |
| `X-Hub-Time` | время запроса, секунды Unix; дальше 5 минут от часов сервера — 404 |
| `X-Hub-Nonce` | случайная строка 16–64 знака `[A-Za-z0-9_-]`, второй раз — 404 |
| `X-Hub-Signature` | HMAC-SHA256, ключ `PLATFORM_API_SECRET`, hex |

Подписывается строка из пяти строк через `\n`: метод (`GET`/`POST`), путь с запросом (`/api/platform/licenses?q=abc`,
запрос собран через `URLSearchParams`), время, nonce, sha256 тела в hex (у GET — от пустой строки). Тело POST — объект
JSON (`JSON.stringify`), не больше 4,4 МБ (файл договора до 3 МБ в base64); остальным адресам сервера — 64 КБ.

Использованные nonce — таблица `platform_nonces` (nonce, до какого времени помнить); устаревшие стираются при каждой
записи. Деньги — свои таблицы (раздел «Договоры и деньги» ниже).

## Пароль для опасного

Заблокировать ключ, удалить ключ, отозвать компьютер, удалить пробный период, опубликовать обновление, удалить
начисление, поступление, договор или файл договора — только с
паролем админки Strassio в теле: `"adminPassword": "…"` (переменная `ADMIN_PASSWORD` в Vercel; хаб его не хранит).
Решение владельца 2026-11-08. Неверный пароль 10 раз за 15 минут — дальше `429` и для верного.

## Ответы

Успех — `{"ok": true, …}`. Ошибка подписанного запроса — `{"ok": false, "error": "<код>"}`:

| Код | HTTP | Что |
| --- | --- | --- |
| `missing` | 404 | нет такого ключа, заявки, компьютера или пробного периода |
| `bad_request` | 400 | неверные данные (срок, версия, ссылка, SHA-256, код компьютера, состояние заявки) |
| `bad_client` | 400 | неверная почта, Telegram или день рождения клиента |
| `confirm` | 400 | при удалении ключа не совпали последние 4 знака |
| `already_has_key` | 409 | по заявке уже создан ключ (в ответе `serial`) |
| `password_required`, `wrong_password` | 403 | нет пароля админки или он неверный |
| `password_not_set` | 503 | в Vercel нет `ADMIN_PASSWORD` (короче 8 знаков) |
| `too_many_requests` | 429 | слишком много неверных паролей |
| `github` | 502 | «Заполнить из GitHub» не получилось, причина в `details` |
| `already_paid` | 409 | долг уже оплачен целиком |
| `too_much` | 400 | поступление больше остатка долга |
| `no_rate` | 409 | поступление другой валютой, а курса нет (ни своего, ни ЦБ за сегодня или раньше) |
| `bad_base` | 400 | основной тариф не найден, сам от другого тарифа или договорный |
| `not_forever` | 409 | обновления покупаются только к ключу «навсегда» |
| `too_many_files` | 409 | у договора уже 10 файлов |
| `bad_day`, `bad_rate` | 400 | курс от хаба: день не вчера/сегодня/завтра или курс дальше 20% от прежнего |

| `rate` | курс ЦБ на сегодня: `day`, `rate` (сумов за $1), `fresh` (`false` — курс дня не получен, это последний известный) |

| `trials` | пробные периоды: всего, идут, список с днями |
| `updates` | что сейчас получают плагины в stable и beta |
| `release?channel=stable\|beta` | последний выпуск strassio-releases: версия, ссылка, SHA-256 (сервер считает сам), что нового: `notesRu` из раздела «Что нового», `notesEn` из «What's new» (нет раздела — пусто) |
| `audit?limit=` | журнал действий (по умолчанию 200, до 500): кто (`admin`, `hub`, `client`, `site`), что, ключ. Фильтры: `serial`, `who` (`hub` — хаб и старая админка, `client`, `site`), `action` (код действия), `from` и `to` (`ГГГГ-ММ-ДД` по Ташкенту, оба дня включительно) |

Оплата в `licenses`, `extend`, `payments`, `requests/<id>/key`: `tariff` (id включённого тарифа или строки договора;
`key` — по цене ключа), `periods` (1–36: заплатил вперёд за 3 месяца — 3, срок × 3 и цена × 3), `amount` (своя сумма —
скидка; `0` или `free` — бесплатно, с заметкой; пусто — цена × периоды), `currency`, `method` (`cash`, `card`,
`transfer` или `debt` — в долг), `paidNow` (заплатил сейчас часть, остальное — долг), `dueOn` (срок оплаты долга;
нет — день оплаты по договору), `payNote` (`note` у `payments`). Ни тарифа, ни суммы — оплаты нет. Новый ключ по
тарифу получает цену ключа (`terms`), дальше продлевается по ней. Скидка за количество ставится сама на цену тарифа
(не на свою сумму). Оплата помнит ключ по номеру: удалённый ключ не стирает доход. В журнале: `payment`, `paid`,
`payment_delete`, `part_delete`, `tariff`, `contract`, `terms`, `auto_block`, `auto_unblock`, `rate`.

## Договоры и деньги

Владелец 2026-11-08: «для каждого клиента разная цена, потому что договор есть договор». План — хаб,
`.claude/plans/strassio-contracts.plan.md`.

- **Договор** (`contracts`): `number`, `signedOn`, `validFrom`, `validUntil` (`ГГГГ-ММ-ДД`), `party` (сторона, до 200),
  `inn`, `address`, `terms` (условия, до 300), `payDay` (день оплаты 1–31), `currency`, `note`; цены: `month`,
  `discount3`, `discount6`, `discount12` (скидка в % на 3, 6, 12 месяцев; пусто — такого срока нет), `forever`,
  `updates` (обновления на год для «навсегда»); `moveKeys` — перевести ключи клиента на новые цены. Цены договора
  хранятся строками `tariffs` с `contractId` (Месяц, 3 месяца, 6 месяцев, Год, Навсегда, Обновления на год).
- **Цена ключа** (`key_terms`, по ключу): тариф, название, срок, цена, валюта, договор; `updatesUntil` у «навсегда»
  (3 месяца с даты ключа включены). Цена договора выросла — старые ключи остаются на старой, пока не нажали
  «перевести ключи».
- **Начисление** (`payments`): сумма, валюта, `listPrice` (цена без скидки), срок оплаты `dueOn`; `paidAt` пусто — долг.
  **Поступления** (`payment_parts`): сумма, валюта, курс, сколько засчитано, способ. Доход считается по поступлениям.
- **Курс** (`usd_rates`, по дню): сервер спрашивает сразу cbu.uz, AllRatesToday и depozit.uz и берёт первый ответ
  (серверам Vercel cbu.uz не отвечает); все молчат — 15 минут не спрашивает, берёт последний известный. Хаб может
  прислать курс сам (`rates`). Свой курс в поступлении (`rate`) — главнее.
- **Автоблокировка**: каждое утро (хаб вызывает `daily`) ключ с долгом, просроченным на 5 дней, блокируется (`auto_block`, кто —
  `system`); оплатили долг целиком — разблокируется сам (`auto_unblock`). Ключ разблокировали вручную после
  автоблокировки — второй раз за тот же долг не блокируется.
- **Скидка за количество** (`money_settings`, `volume`): от `minKeys` рабочих ключей у клиента — `percent` от цены.
- Файлы договоров — в базе (`contract_files`, base64), до 10 на договор.

В журнал действия хаба пишутся с `actor = "hub"`.

## Сообщения владельцу и утренняя сводка — через хаб

Своего бота и своего cron у Strassio нет (владелец 2026-11-08: «сделай через админку, чтобы каждый раз не
соединять»). Бот один — у хаба little_7o7 (его `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `CRON_SECRET` — в Vercel
хаба). В Vercel Strassio для этого ничего не вносится; `HUB_URL` — адрес хаба (по умолчанию
`https://little-7o7.vercel.app`), на него идут сообщения и с него ссылки в них.

- **Сразу** (новая заявка с сайта, новая активация ключа на компьютере): Strassio шлёт `POST <HUB_URL>/api/notify/strassio`
  с телом `{"text": "<HTML Telegram, до 4000 знаков>"}`, подписанный той же парой и теми же заголовками `X-Hub-*`,
  что и запросы хаба сюда (в подписанной строке путь `/api/notify/strassio`, поэтому подпись не подходит ни к одному
  адресу `/api/platform`). Хаб проверяет подпись и nonce и шлёт текст своим ботом. Хаб не ответил — заявка и
  активация всё равно проходят. Нет пары ключей — сообщений нет.
- **Каждое утро** хаб (свой cron, 9:10 по Ташкенту) вызывает `POST /api/platform/daily` → `messages` (готовые
  тексты, шлёт хаб) и `blocked` (сколько ключей заблокировано за долг). Внутри: сначала автоблокировка долгов; потом заявки и активации за сутки, закончившиеся
пробные (и сколько без покупки), ключи, у которых срок кончается через 7 дней и меньше, с телефонами, дни рождения
сегодня с готовым поздравлением, и деньги: заблокированные за долг, поступления за сутки, сегодня срок оплаты,
просрочено (с датой блокировки), «напомнить о продлении» (ключ кончается через 3 дня, ссылка на готовое сообщение),
заявки без ключа 2 дня, 1-го числа — сколько ждём в этом месяце. По понедельникам — ещё «Итог недели»: ключи, доход, новые клиенты и заявки за 7 дней рядом с прошлыми 7
днями (первым сообщением), долги со списком. Нечего сказать — `messages` пустой.

## Сайт: цены

`GET /api/prices` — открытый адрес (не платформа): общие тарифы ключа в долларах с галочкой «на сайте» (курса на сайте нет) → `prices` (`id`, `name`,
`days`, `price`, `currency`, `label`). Главная показывает раздел «Цены» с кнопкой «Купить» → `/buy?tariff=<id>`; там
тариф уже выбран. Заявка (`POST /api/site/request`) с `tariff` — первой строкой «Тариф: Год — $96» (цена из базы).
