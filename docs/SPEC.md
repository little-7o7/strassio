# Strassio — техническое задание

Версия ТЗ: 1.0 (сентябрь 2026). Документ живой: решения, принятые в процессе разработки, дописываются сюда.

Метки приоритета: **[P1]** — первая рабочая версия, **[P2]** — сразу после неё, **[P3]** — позже.
Метка **[NEW]** — функции, которых нет в rStones (по крайней мере в известном нам виде).

---

## 1. Цель и рамки

Strassio — плагин для CorelDRAW, который создаёт шаблоны страз из линий и фигур, нарисованных пользователем.
Каждая страза — круг заданного диаметра (диаметр отверстия в шаблоне).

**Делаем:** стразы по линиям, заливку форм, исправление пересечений, удаление и правку камней, цвета камней,
векторные инструменты для подготовки линий, мотивы, проверки для производства внутри CorelDRAW, настройки,
русский и английский интерфейс, лицензию, обновления, установщик.

**Не делаем:** фото и растр в стразы (включая растровую заливку), встроенный каталог камней,
расчёт заказа и стоимости, экспорт DXF (пользователь делает сам средствами CorelDRAW).

**Исключение — G-code для сверления шаблона** (решение автора 2026-11-07: «добавить функции ArtCAM, у меня
много свёрл, нужен G-code .tap»): стразы → файлы .tap по свёрлам, раздел 11.1. Фрезеровка, рельефы и прочее
из ArtCAM — нет.

## 2. Кнопка и окно плагина

### 2.1 Кнопка запуска [P1]
- Своя панель инструментов «Strassio» с кнопкой-камнем (`assets/icon/strassio-stone.*`).
- Нажатие открывает докер, повторное — закрывает.
- Кнопку можно перетащить на любую панель CorelDRAW. Дубль в меню «Окно → Докеры → Strassio».

### 2.2 Докер [P1]
Раскладка по умолчанию — вертикальная (как обычные докеры справа). Горизонтальная — в настройках (раздел 12).

Сверху вниз:
1. **Шапка:** название, статус лицензии, кнопка настроек (шестерёнка), справка.
2. **Выбор камня:** размер (ss6 — 2,4 мм…) и цвет с образцом цвета. Сетка образцов, а не только список.
3. **Вкладки:** Линия · Заливка · Правка · Цвет · Векторы · Мотивы.
4. **Метод:** выпадающий список с маленькой картинкой-схемой у каждого метода (свои иконки, не копия rStones).
5. **Параметры выбранного метода.** Только нужные этому методу поля.
6. **Низ:** «Предпросмотр», «Создать», строка подсказки. Подсказки у всех полей на двух языках.

Внешний вид — собственный, светлая и тёмная темы.

**Компактный режим** (сделано 2026-11-07, пункт TRW-4): кнопка в шапке рядом с шестерёнкой прячет все
подсказки под полями (стиль `Strassio.Muted`, кроме строк лицензии, обновления и статуса) и уменьшает поля
докера с 10 до 6. Всплывающие подсказки остаются. Режим хранится в настройках (`compact`).

## 3. Таблица камней и цвета

### 3.1 Размеры [P1]
- Таблицу заполняет пользователь: **название + диаметр**, например `ss6 — 2,4 мм`, `ss5 — 2,1 мм`, `ss8 — 2,5 мм`.
- Добавить, изменить, удалить, изменить порядок — прямо в плагине.
- **Наборы таблиц** [P2]: несколько таблиц (например, под разных поставщиков), переключение одним кликом.

### 3.2 Цвета [P1]
- У каждого размера свой список цветов, количество не ограничено (обычно 4–5).
- Цвет: название + RGB (опционально CMYK).
- Модель хранения (`%APPDATA%\Strassio\stones.json`):

```json
{
  "sets": [{
    "name": "Основной",
    "sizes": [
      { "name": "ss6", "diameterMm": 2.4, "colors": [
        { "name": "Красный", "rgb": "#E53935" },
        { "name": "Зелёный", "rgb": "#43A047" },
        { "name": "Кристалл", "rgb": "#E8EEF5" }
      ]}
    ]
  }]
}
```

### 3.3 Как выглядит камень в документе [P1]
- Круг с заливкой цветом камня. Обводка — по настройке: нет / волосяная / заданной толщины.
- Имя объекта: `ss6 Красный` — видно в диспетчере объектов.
- Результат одной операции — одна группа с понятным именем (например, `Strassio: линия ss6 Красный`).

### 3.4 Функции цвета
- Перекрасить выделенные камни [P1].
- Выделить все камни данного размера / цвета / размера+цвета [P1].
- Пипетка камня: взять размер и цвет с камня и применить к выделенным [P2] [NEW].
- Случайное смешение 2–3 цветов в процентах (например, 70% кристалл / 30% золото) [P2] [NEW].
- «Равномерно» (2026-11-06, режим по умолчанию): доли те же, но камни одного цвета по возможности не стоят рядом
  (`ColorMixer.Even`: раскладка по порядку страз, потом обмены с соседями; редкий цвет разводится сильнее).
- Чередование цветов вдоль линии по шаблону (например, К-К-Б) [P2] [NEW].
- Цвет крайних рядов (2026-11-06): у выделенных страз 1–10 рядов от края (внешнего и у больших отверстий)
  перекрашиваются в выбранный цвет. Край ищется по самим стразам (`EdgeRows`: пустой сектор вокруг камня шире
  100°, дырка от одного камня краем не считается), поэтому работает с любым методом и с камнями руками.
- Плавный переход цвета вдоль линии или заливки через постепенное смешение [P3] [NEW]. Сделано (2026-11-06):
  «Омбре» в «Смешать цвета» — слева направо, сверху вниз, от центра к краю, вдоль линии; 2–3 цвета
  (`ColorMixer.Ombre`: доля следующего цвета растёт по рисунку, раскладка без кучек, переход не размывается).
- Все цвета камней добавляются в палитру документа CorelDRAW [P2] [NEW].

## 4. Стразы по линии

У rStones три метода: по кривой, вокруг кривой, по смещённой кривой. У нас — те же три плюс новые.

### Общие параметры всех методов
- Зазор между камнями, начальная точка, отступ от концов, направление.
- **Шаг:** подгонка (ровно без дырки в конце) / точный шаг / точное количество камней.
- **Углы:** в каждом остром углу (порог угла — настройка) камень ставится точно в вершину,
  затем каждый отрезок между углами заполняется отдельно. Замкнутые кривые — равномерно, без «шва».

### Методы
- **L1. По линии** [P1] — один ряд.
- **L2. Вокруг линии** [P1] — N рядов в обе стороны или только в одну; расстояние между рядами;
  рядам можно дать шахматный сдвиг. **Разный размер для каждого ряда** (центр ss10, края ss6) [NEW].
- **L3. По смещённой кривой** [P1] — ряд на расстоянии от линии внутрь/наружу, углы круглые или острые.
- **L4. Переменная ширина («каллиграфия»)** [P2] [NEW] — число рядов меняется вдоль линии:
  1 на концах → N в середине, или от начала к концу. Живые мазки вместо «трубы» одинаковой ширины.
- **L5. Переход размера вдоль линии** [P2] [NEW] — например ss10 → ss6 → ss5. Стебли, кончики листьев.
- **L6. Чередование размеров по шаблону** [P2] [NEW] — например ss6, ss6, ss10.
- **L7. Пунктир** [P2] — группы по N камней, пропуск M.
- **L8. Акценты** [P2] [NEW] — крупный камень на концах линии и/или в углах.
- **L9. Мотив по линии** [P3] — см. раздел 9.

## 5. Заливка формы

У rStones: сетка, сетка со сдвигом, «остров» (контурная), по центральной линии, переход (blend), формами,
случайная, растровая. Растровую не делаем. Остальные делаем и добавляем новые.

### Общие параметры
- Зазор, отступ от края, корректная работа с отверстиями в форме (буквы «О», «А», кольца).
- Текст заливается после перевода в кривые (плагин может предложить сделать это сам).
- **Автоподбор сетки** [P2] [NEW]: плагин перебирает сдвиг и угол сетки и выбирает вариант, где у края
  больше целых камней и меньше дыр.
- **Живой предпросмотр** [P2] [NEW]: при изменении параметров результат обновляется сразу.

### Виды заливки
- **F1. Сетка (квадратная)** + угол поворота [P1].
- **F2. Соты (шахматная)** + угол поворота [P1].
- **F3. Контурная** — ряды от края внутрь, повторяя форму; центр аккуратно добивается [P1].
- **F4. Комбинированная** — N контурных рядов по краю + сетка или соты внутри [P1] [NEW].
- **Шов в F3/F4** (сделано 2026-11-06, `SeamSmoother`): где ряды середины упираются в крайнее кольцо или
  кольца сходятся посередине, оставалась цепочка дырок. После заливки ищутся дырки (точки глубже камня
  от края, куда между камнями влезает круг больше 0,44 камня); камни в 2,5 шага от них чуть раздвигаются:
  каждый отталкивается от соседей ближе 1,26 × (вплотную с зазором), в ровных сотах силы уравновешены,
  у дырки камень смещается в пустоту. До 60 проходов, шаг не больше 0,08 камня, камень не выходит из
  формы и не подходит к соседу ближе зазора. Крайние ряды (F4 — все N колец) не двигаются. Где после этого
  влез целый камень — кладётся. На листе, сердце, овале, капле, ленте пустоты внутри стало в 3–40 раз
  меньше. Квадратная сетка в середине не сглаживается (иначе станет сотами).
- **F5. Кант** — только N рядов по краю, внутри пусто [P1].
- **F6. По центральной линии** [P2].
- **F7. Переход между двумя кривыми** (ряды плавно перетекают от одной линии к другой) [P2].
- **F8. По направляющей** — пользователь рисует линию, ряды внутри формы повторяют её изгиб [P2] [NEW].
- **F9. От центра** — кольца или спираль [P2] [NEW].
- **F10. Случайная плотная** — без наложений, с минимальным расстоянием; можно в нескольких размерах [P2].
- **F11. Градиент размера** — крупные в центре, мелкие к краю (или слева направо) [P2] [NEW].
- **F12. Добивка щелей** — основной размер + мелкие камни в оставшихся промежутках [P2] [NEW].
- **F13. По толщине штриха** — один ряд по середине буквы или мазка кистью, размер камня следует
  ширине: в тонком месте самый мелкий камень (поле «Самый мелкий камень»), в толстом — до основного,
  все размеры таблицы между ними тоже идут в дело [NEW] (сделано 2026-11-06).
  - Середина — та же центральная линия, что в «Векторе» (раздел 10), но без сглаживания, и каждая её
    точка подтягивается поперёк туда, где до края дальше всего (иначе в полоске ровно под ss10 вставал ss6).
  - Размер в точке — самый крупный камень, который целиком помещается с отступом от края. В волосяной
    линии, где не помещается даже мелкий, мелкий всё равно ставится, если вылезает не больше чем на
    четверть, — иначе ряд рвался бы в каждой тонкой засечке. Одинокий крупный камень среди мелких
    («бусина» короче самого камня) заменяется размером соседей.
  - Свободные концы продлеваются к кончику мазка, пока там помещается мелкий камень. Крайний камень —
    тот, что краем ближе к концу; почти поровну — крупнее (у тупого конца крупный касается края).
  - Линия режется в резких поворотах (больше 50° на отрезке около камня): у Т, А, Н, К ряды ножки и
    перекладины ставятся отдельно; сначала самый длинный кусок, следующие начинаются там, где камни
    не задевают поставленные. Просветы между соседями — заданный зазор с учётом размеров обоих, остаток
    длины раздаётся поровну.
- **F14. Растворение** — плотность плавно падает к краю или в заданном направлении [P3] [NEW] (сделано 2026-11-06).
- **F15. Лучи** — линии страз от самой глубокой точки формы к краю (подсолнух, веер) [NEW] (сделано 2026-11-06).
  Шаг вдоль луча — «камень + зазор»; соседние лучи по хорде не ближе «камень + между лучами». На первом
  круге (радиус «пусто в центре» + полкамня) — столько лучей, сколько влезет; дальше каждый раз, когда
  между двумя лучами помещается третий, он начинается посередине. Луч обрывается у края формы.
- **F16. Штрихи** — прерывистые параллельные полоски (икат, «дождь») [NEW] (сделано 2026-11-06).
  Линии под углом «Направление» через «камень + между линиями», соседние сдвинуты на полшага. На линии —
  штрихи случайной длины от трети «Штрих до» до «Штрих до» и разрывы от 1 до «Разрыв до». «Редеет» — та же
  карта, что у F14: там штрихи короче (до 0,2 длины), разрывы длиннее (до 5 раз). «Вариант» — случайность.
  - Основа — соты с шагом «камень + зазор». Местный просвет растёт от «Зазора» до «Просвета в конце»
    по плавной кривой (t² · (1,6 − 0,6t)), где t — 0 в плотном месте и 1 в самом редком: к краю (по
    глубине формы), к середине, вправо, влево, вверх, вниз.
  - Какие узлы сот оставить, решает рассеивание ошибки (как полутона в печати): плотность узла —
    (шаг / (камень + просвет))², половина ошибки уходит следующему узлу ряда, по четверти — двум соседям
    в следующем ряду, ряды обходятся змейкой, порог чуть случайный. Плотная часть — целые соты, дальше
    камни выпадают поодиночке, без кучек и дыр.
  - В редкой части камни сдвигаются в случайную сторону не дальше половины «лишнего» просвета, чтобы
    не читалась сетка; ближе зазора к соседу камень не подходит. «Вариант» задаёт случайность.
- **F17. Волны** — параллельные волнистые линии [NEW] (сделано 2026-11-07). Линия — синусоида «Высота
  волны» × «Длина волны», повёрнутая на «Направление». Соседние линии сдвинуты поперёк на (камень + между
  линиями) / cos(atan(A·k)) — на самом крутом месте волны просвет между линиями не меньше заданного. Камни
  ставятся шагом «камень + зазор» по хорде, одинаково для всех линий — соседние линии идут в такт.
- **F18. Заливка мотивами** [P3] (сделано 2026-11-07, не методом, а на вкладке «Мотивы»: «Россыпью внутри
  фигуры», см. раздел 9).
- **F19. Цветные полосы** — чередование цветов полосами под углом [P3] [NEW].

## 6. Исправление пересечений (Fix intersections) [P1]

Главное требование — правильная работа в углах.

### 6.1 Профилактика при создании
- Камень в вершине каждого острого угла, отрезки между углами заполняются отдельно (раздел 4).
- Для рядов вокруг линии: на внутренней стороне острого угла смещённая кривая образует петлю —
  петля вырезается ДО расстановки камней. Внешняя сторона обходит угол дугой.

### 6.2 Проверка
- Конфликт: расстояние между центрами `< r1 + r2 + minGap − допуск`.
- Область: выделенные камни / весь слой / между двумя выделенными группами.
- Поиск через пространственную сетку (ячейка = максимальный диаметр + зазор). Цель: 50 000 камней < 1 с в Core.

### 6.3 Кто остаётся
Порядок приоритета (настраиваемый), по умолчанию:
закреплённые → угловые и акцентные → главный ряд → более крупные → верхние по порядку объектов.
Удаляется камень с меньшим приоритетом.

### 6.4 Действия
- **Удалить** / **Сдвинуть** (сдвиг вдоль своей линии в пределах лимита, иначе удалить) / **Только показать**
  (подсветить конфликты, ничего не менять).
- После удаления соседние камни той же линии раздвигаются, чтобы не осталось дырки.

### 6.5 Тестовые фигуры (обязательно в Preview и тестах)
Звезда, сердце, зигзаг с углом 20°, тугая спираль, S-кривая, буквы с касающимися частями.

## 7. Удаление и правка камней

### 7.1 Режимы удаления (утверждены автором) [P1]
1. **Оставить верхние, удалить нижние.** Камни, которые лежат над линией, не трогаем, а мешающие им снизу убираем.
2. **Удалить верхние, оставить нижние.**
3. **Удалить по линии.** Выбираете линию, и все стразы, которые она пересекает, удаляются. Это как «разрезать» заливку.
4. **Удалить внутри или снаружи выбранной формы.**
5. **Сдвинуть вместо удаления**, если камень можно подвинуть так, чтобы он встал без наложения.

### 7.2 Инструменты правки
- Удаление дублей (камни друг на друге после копирования) [P1].
- Закрепление камней: их не трогают пересечения и удаление [P1] [NEW].
- Замена размера в выделенном (ss6 → ss10) с перерасстановкой по той же линии [P2].
- Выравнивание расстояний вдоль линии после ручного перемещения [P2]. Сделано (2026-11-06): «Показать неровные
  просветы» и «Выровнять просветы» (`GapEvener`): сдвиг вдоль ряда не дальше предела, концы, углы и закреплённые
  стоят, просвет не меньше зазора из настроек.
- Притянуть камни к линии [P2].
- Поиск дырок: подсветить пустые места, куда помещается камень, и заполнить одним кликом [P2] [NEW].

## 8. Новые функции для страз [NEW]

- **«Живые» стразы** [P2]: группа камней запоминает исходную линию/форму и все настройки.
  Пользователь правит линию → «Обновить» → камни перестраиваются. Метаданные хранить на группе
  (`Shape.Properties` или ObjectData — проверить, что работает начиная с X7).
- **Масштабирование с сохранением размера камней** [P2]: дизайн меняет размер, камни пересчитываются
  в правильном диаметре (обычное растягивание CorelDRAW портит диаметры).
- **Россыпь** [P3]: случайные камни вокруг дизайна с минимальным расстоянием, эффект «брызг». Сделано
  (2026-11-06): вкладка «Мотивы» → «Россыпь вокруг». Дизайн — выделенные стразы и/или замкнутые фигуры.
  Диск Пуассона с переменным просветом (`Scatter.Splash`): расстояние до дизайна — до края ближайшей стразы
  или до контура фигуры снаружи; у дизайна — основной камень и просвет max(зазор, 0,2 камня), к краю
  россыпи (поле «ширина», по умолчанию 12 мм) — мельче (до «Самого мелкого камня», не больше четырёх
  размеров) и реже (просвет до «камень + ширина/4»). Внутрь фигур и на готовые стразы страницы камни не
  ставятся. Каждое нажатие — новая случайность (Ctrl+Z и ещё раз).
- **Обводка всего дизайна рядом страз** на заданном отступе [P2].
- **Симметрия** [P3]: делаете половину или четверть, плагин зеркалит и убирает камни на осях. Сделано
  (2026-11-06): «Правка» → «Отразить» (половина вправо/влево/вниз/вверх, четверть → целое, по выделенной прямой).
  Ось — через центры крайних страз; камень у самой оси встаёт на ось и не копируется (`Symmetry`); копии —
  дубликаты исходных кругов (размер, цвет, имя, группа).
- **Пресеты** [P2]: наборы настроек («Стебель тонкий», «Лепесток плотный»), применение в один клик.
- **История последних настроек и горячие клавиши** [P2].

## 9. Мотивы [P3]

Мотив — готовый элемент из страз (цветок, листик, завиток), сохранённый для повторного использования.

- Библиотека мотивов: «Сохранить как мотив» из выделенных камней, превью-картинка, папки.
- Мотив по линии: шаг, поворот по направлению линии, чередование нескольких мотивов.
- Мотив по кругу: N копий вокруг центра (розетки, мандалы).
- Рамки и бордюры: мотив по контуру прямоугольника/овала/любой формы, отдельная обработка углов.
- Заливка формы мотивами.

Хранение: `%APPDATA%\Strassio\motifs\`.

Как сделано (2026-11-06, вкладка «Мотивы», `Strassio.Core.Motifs`):

- Мотив — список страз относительно середины габарита: сдвиг X/Y, диаметр, имя размера, имя цвета и RGB
  заливки (чтобы нарисовать мотив, даже если цвета нет в таблице). Один мотив — один файл JSON.
- Локальные оси мотива: +X — вдоль линии, +Y — «верх». Разомкнутая линия: «верх» слева по ходу.
  Замкнутая обходится по часовой стрелке — «верх» наружу; так из круга и мотива получается розетка.
  «Перевернуть» — зеркально по Y. Направление — по хорде на ширину мотива, чтобы на извилистой линии
  мотивы не «дрожали».
- По линии: «Сколько» = 0 — сколько влезет с промежутком (крайние мотивы — у концов линии, остальные
  поровну); иначе ровно столько. Второй мотив — через один.
- Рамка: углы — поворот линии больше 40°; мотив углов повёрнут «верхом» по биссектрисе наружу; стороны
  между углами заполняются целым числом мотивов поровну, с отступом от угла на полмотива углов + промежуток.
  Фигура без углов — как «по линии».
- «Повторить по кругу» (мандала): копии выделенных страз вокруг середины выделенной фигуры-центра,
  N раз всего; копии — дубликаты исходных фигур (тот же размер, цвет, имя).
- Камень, который налез бы на уже поставленный (зазор — «Зазор» из параметров), не ставится, и итог
  говорит сколько таких.
- «Россыпью внутри фигуры» (заливка мотивами, сделано 2026-11-07, `MotifPlacer.Fill`): мотив занимает круг
  радиуса R (самый дальний камень от середины + полкамня); середины мотивов — случайные точки внутри
  замкнутых фигур (чёт-нечет, дырки пустые), не ближе 2R + «Промежуток» друг к другу (сетка с клеткой
  шаг/√2). Мотив ставится, только если влезает в фигуру целиком и его камни не налезают на уже
  поставленные. Два мотива — по очереди. «Поворачивать» — случайный угол у каждой копии. Каждое нажатие —
  новая россыпь.
- «Штрихи вокруг» (сделано 2026-11-07, `PatternFills.StreaksAround`): линии F16 по всей области вокруг
  дизайна; камень ставится, если расстояние от края дизайна (фигуры или камня) от «полкамня + зазор» до
  того же плюс «ширина россыпи». Чем дальше от дизайна, тем штрихи короче и разрывы длиннее (карта
  «Редеет» = расстояние / ширина). Не налезают на дизайн и на готовые стразы рядом.

### 9.1 Раппорт — повтор плитки по ткани (сделано 2026-11-06)

Автор делает в основном ткани целиком: одна плитка рисунка повторяется по всей ширине (`Strassio.Core.Motifs.Repeat`).

- Сдвиг копий: ровной сеткой; «полшага вниз» — каждый второй столбец опущен на половину шага; «кирпич» —
  каждый второй ряд сдвинут вбок на половину шага. Столбцы идут вправо, ряды — вниз, исходная плитка —
  левая верхняя.
- Шаг: свой (поля «Шаг ↔» и «Шаг ↕»), иначе размер рамки — самой большой выделенной фигуры, которая не
  страза; иначе габарит страз плюс зазор. Рамка не копируется.
- Стыки: для бесконечного повтора (векторы сетки копий) ищутся пары «страза плитки — страза соседней копии»
  ближе, чем «полсуммы диаметров + зазор». Из каждой пары, начиная с самых сильных наложений, убирается
  страза дальше от середины плитки — она и вылезла за край. Удаление идёт из самой плитки, поэтому чисто
  на всех стыках сразу, сколько бы копий ни было.
- Копируются выделенные фигуры верхнего уровня (группы целиком — одна команда CorelDRAW на копию).
  У копий «живых» групп рецепт снимается, чтобы «Обновить» не пересобрал их на месте оригинала.
- Раппорт из двух мотивов (2026-11-07): каждая вторая копия в шахматном порядке ((столбец + ряд) нечётно)
  повёрнута на 180° или отражена (слева направо, сверху вниз) вокруг середины рамки (без рамки — середины
  страз). Стыки проверяются для двух опорных копий — обычной и повёрнутой — против всех копий вокруг.
  В CorelDRAW копия поворачивается/отражается на месте и сдвигается так, чтобы середина её габарита
  встала туда, куда её переносит поворот вокруг середины плитки.
- Лист без шва (2026-11-07, `Repeat.SeamlessSheet`, `Repeat.FillSheet`): период узора по ширине — шаг, а у
  «полшага» и у раппорта с повёрнутой копией — два шага; по высоте — шаг, у «кирпича» и повёрнутой копии —
  два. Лист = наибольшее целое число периодов, не больше заданного листа. Страза попадает на лист, если её
  центр внутри (левый и верхний край — свои, правый и нижний — соседа), поэтому листы встык дают ровно
  ту же ткань. Лист ставится справа от плитки (20 мм), красная рамка — край листа.
- Камней на метр ткани (2026-11-07): плиток на погонный метр = ширина ткани × 1000 / (шаг ↔ × шаг ↕), у
  всех видов сдвига одинаково. Камни плитки без страз со стыков по размерам и цветам × плиток, округление
  вверх. Таблица — в буфер обмена, как у «Посчитать камни».
- Обрезать по рамке (2026-11-07, `FrameTrim.Outside`): рамка — замкнутые фигуры выделения (чёт-нечет).
  «Целиком внутри» — центр внутри и до края рамки не меньше радиуса; «центр внутри» — только центр.

### 9.2 Готовые мотивы и рамки в комплекте (сделано 2026-11-07, пункт TRW-2)

`Strassio.Core.Motifs.StarterMotifs`: 27 мотивов — сердце (контур и залитое), звезда (контур и залитая),

### 10.1. Надпись стразами одной кнопкой (сделано 2026-11-06)
Вкладка «Текст». Выделяется обычный текст CorelDRAW (читается через DisplayCurve, сам текст не
меняется) или буквы в кривых. Три способа:
- **Один ряд по середине букв** — метод F13 «По толщине штриха», поле «Самый мелкий камень».
- **Обвести буквы** — F5 «Кант» ровно в один ряд по краю каждой буквы изнутри.
- **Залить буквы** — F3 «Контурная» с узором середины из параметров.

Зазор и отступ от края — общие параметры методов. Перед расстановкой и по кнопке «Проверить надпись»
(`Strassio.Core.Vector.TextCheck`):
- **Буквы.** Контур целиком внутри нечётного числа других — дырка своей буквы; заходящий в другой
  только частью — отдельная буква (рукописные шрифты, где буквы налезают).
- **Тонкие буквы.** Толщина штриха меряется по средней линии каждой буквы через 0,2 мм; «обычная» —
  медиана. Нужно: обвести — два камня, зазор и два отступа (иначе ряды с двух краёв штриха
  налезут); залить — камень и два отступа; по середине — самый мелкий камень и два отступа. Если
  обычный штрих тоньше — совет «увеличьте надпись в N раза». Тонкие места длиннее половины камня
  (по середине — где штрих меньше половины мелкого камня) помечаются красными кружками.
- **Тесный интервал.** Буквы, между которыми меньше камня (с учётом отступов; по середине — меньше
  половины камня), сольются в стразах — совет «раздвиньте буквы ещё на X мм», место помечается.
- **Нахлёст.** Налезающие буквы надо объединить в CorelDRAW, иначе нахлёст станет дыркой.

Пометки создаются в той же группе отмены, что и стразы. Картинки — `dotnet run --project
tools/Strassio.Preview -- text [буквы.json]` → `out/preview/text/`.

### 10.2. Монограмма (сделано 2026-11-07, пункт TRW-1)
Вкладка «Текст», под надписью: поле «Буквы» (1–3), шрифт (любой шрифт системы), рамка (круг, овал, ромб,
скруглённая, щит, без рамки), высота букв. Одна кнопка «Сделать монограмму».

- Буквы — временный художественный текст CorelDRAW нужным шрифтом, его контур (DisplayCurve, запасной
  путь — перевод в кривые) и сразу удаление. Все шрифты знает сам CorelDRAW.
- `Strassio.Core.Motifs.Monogram.Arrange`: общий масштаб по самой высокой букве (строчные остаются
  ниже), из трёх букв средняя × 1,35; середины по высоте на одной оси; между габаритами — камень + зазор.
- Рамка — выпуклая фигура с половиной высоты 1 и шириной по пропорции букв (овал вытянут хотя бы в
  1,25 раза, ромб и щит — в пределах), увеличенная двоичным поиском до наименьшего размера, при котором
  все вершины выпуклой оболочки букв внутри и не ближе «полтора камня + зазор» к линии рамки.
- Буквы раскладываются выбранным выше способом надписи, рамка — L1. Буквы и рамка остаются кривыми
  в документе («живые» стразы обновляются при их правке). Всё — одна группа отмены, результат выделен,
  стоит в центре страницы.
- Картинки: `dotnet run --project tools/Strassio.Preview -- monogram [буквы.json…]` → `out/preview/monogram/`.

### 11.1 Сверление шаблона на станке: G-code [P2] [NEW]

Решение автора 2026-11-07. Кнопка «Сверление на станке (G-code)…» в блоке «Производство». Код: ядро —
`Strassio.Core.Cnc` (`DrillPlanner`, `PathOrder`, `GCodeWriter`, `GCodeCheck`), окно — `DrillWindow`,
CorelDRAW — `Docker.Drill.cs`; настройки — `drill.json` рядом с `settings.json`.

- **Отверстия** — выделенные стразы, иначе вся страница; центр и диаметр круга, размер и цвет из меток.
  Стразы друг на друге (ближе 0,05 мм) одним сверлом сверлятся один раз.
- **Сверло для размера**: своё правило «размер → сверло» → ближайшее из списка свёрл пользователя (при
  равенстве — большее, чтобы камень пролез) → ровно по диаметру отверстия, если список пуст. Номер
  инструмента T — место сверла в списке. Разница сверла и отверстия больше 0,2 мм — предупреждение.
- **Ноль станка** — общий для всех свёрл и цветов (шаблоны совпадают). По умолчанию — на доске (решение автора
  2026-11-07, как модель в ArtCAM): размер доски W × H (0 — как страница CorelDRAW), доска отложена от левого
  нижнего угла страницы, ноль — любой из четырёх углов доски или её центр. Оси обычные (X вправо, Y от себя),
  от верхнего/правого угла координаты отрицательные. Отверстие хоть краем за доской — сохранить нельзя.
  Можно и без доски: левый нижний угол рисунка по краю отверстий, центр рисунка или ноль документа.
  Z0 — верх материала.
- **Порядок обхода**: от нуля «ближайший следующий», потом 2-opt (сетка соседей, предел 1,5 с на сверло).
  10 000 отверстий — доли секунды.
- **Файлы**: по файлу на сверло (по умолчанию; имя «основа_номер_Dдиаметр_размеры.tap») или один файл со
  сменой T… M6; по желанию — ещё и по цветам. Имена и пояснения — латиницей (транслит), концы строк CRLF,
  числа с точкой и тремя знаками.
- **Формат по умолчанию** — самые совместимые команды: G21 G90 G17, G0 Z безопасная, M3 S, на каждое
  отверстие G0 X Y → G1 Z−глубина F → G0 Z подъём (с шагом — несколько заходов), в конце M5, G0 X0 Y0, M30.
  По желанию — циклы G81/G83 (G99, R = подъём), номера строк N, «%».
- **Самопроверка** (`GCodeCheck`): файл «проигрывается» перед записью — каждое отверстие на месте и на полной
  глубине, X/Y только над материалом, вниз в материал холостым ходом только в уже просверленное, шпиндель
  включён, в конце M30. С ошибкой файлы не пишутся.
- **Показать путь** — путь сверла и крестик нуля на непечатаемом слое «Strassio путь сверла», одна группа отмены.
- **Время** — оценка: холостые переходы, опускание на подаче, по 0,15 с на разгон каждого движения.
- Превью: `dotnet run --project tools/Strassio.Preview -- drill` → `out/preview/drill/` (SVG пути по самим .tap
  и сами .tap).
- Открыто (ждёт ответа автора): пульт станка (Mach3, NcStudio, Richauto DSP, GRBL…) и пример .tap из ArtCAM —
  чтобы повторить формат; материал, глубина и скорости по умолчанию; фрезеровка крупных отверстий по кругу.

## 13. Лицензия

### 13.1 Код компьютера
- Хэш SHA-256 от нескольких аппаратных признаков (через WMI): UUID системной платы/BIOS,
  серийный номер материнской платы, идентификатор процессора, серийный номер физического системного диска.
- НЕ использовать признаки, которые меняются при переустановке Windows (MachineGuid, ProductId).
- Нечёткое сравнение: лицензия остаётся действительной, если изменился один признак из четырёх.
- Показывается пользователю как `XXXX-XXXX-XXXX-XXXX`.

### 13.2 Ключ и активация
- Клиент получает серийный ключ вида `STRS-XXXX-XXXX-XXXX`.
- Активация: плагин отправляет ключ + код компьютера + версии плагина и CorelDRAW на сервер.
- Сервер возвращает файл лицензии: `{serial, hwid, plan, expiresAt, issuedAt, nextCheckAt}`,
  подписанный **ECDSA P-256 / SHA-256**. Подпись встроена и в .NET Framework 4.8 (`ECDsaCng`), и в Node.js,
  сторонние библиотеки не нужны. Формат подписи — IEEE P1363 (r‖s); в Node указать `dsaEncoding: 'ieee-p1363'`.
- В плагине только открытый ключ. Приватный — только на сервере (переменная окружения).
- Проверка лицензии в нескольких местах кода, не только при запуске.

### 13.3 Работа без интернета
- Плагин сверяется с сервером **при каждом запуске CorelDRAW** (решение автора, 22.09.2026), тихо,
  в фоне — докер открывается сразу. Отозванная/перенесённая лицензия снимается при первом же запуске.
  Если CorelDRAW не закрывают — дополнительно **раз в сутки** (таймер проверяет каждый час, пора ли).
  Файл офлайн-активации не сверяется.
- Если сервер недоступен — продолжает работать **до 14 дней** с последней успешной проверки
  (решение автора, 22.09.2026; было 30).
- **Защита от перевода часов** (`TimeGuard`): плагин помнит самое позднее время на часах компьютера,
  самое позднее время сервера (issuedAt последней лицензии) и момент, до которого лицензии запрещены
  (после «Освободить», переноса, отзыва). Метки лежат в `%LOCALAPPDATA%\Strassio` и в реестре HKCU,
  каждая подписана HMAC от кода компьютера. Часы отстают больше чем на 2 часа от любой метки или от
  issuedAt, метки удалены/поправлены/не записываются — состояние «часы переведены»: создавать нельзя,
  пока сверка с сервером не подтвердит время. Сервер прислал лицензию старше уже виденной — не
  принимается (подставной сервер). Попытки обхода — тесты `LicenseAttackTests`.
- Файл офлайн-активации (13.6) помечен `"offline": true` — сверка не требуется, действует до expiresAt.

### 13.3a Активация через сайт (решение автора, 22.09.2026; с версии 0.7.0)
- Ключ в плагине больше не вводится. Окно «Лицензия» — три шага:
  1. **Код этого компьютера** (полный, 4 части через точку) + «Копировать»;
  2. **«Открыть сайт активации»** — браузер открывает `/activate#hwid=<код>` (код ещё и в буфере);
  3. на сайте клиент вводит ключ STRS → получает **код активации** → вставляет в поле «Код активации»
     и нажимает «Активировать».
- Код активации — подписанная лицензия одной строкой `SA1.<payload base64url>.<подпись base64url>`
  (`toActivationCode` на сервере, `ActivationCode.TryDecode` в плагине). Подделать нельзя — подпись
  закрытым ключом сервера; для другого компьютера не подходит — в payload код компьютера.
- Лицензия с сайта обычная (не офлайн): плагин сверяет её с сервером при запуске и раз в сутки,
  поэтому перенесённая/отозванная перестаёт работать.
- Сервер: `POST /api/site/activate {serial, hwid, transfer}` — те же правила, что у активации из
  плагина (тот же компьютер восстанавливается, занято → occupied, перенос раз в 7 дней).
- Страница «Моя лицензия» (/license) — по одному ключу STRS (решение автора, 22.09.2026: ключа
  восстановления RCV больше нет; от перебора — не больше 10 несуществующих ключей за 15 минут с адреса).
- **Брандмауэр.** У многих CorelDRAW закрыт правилом «Block CorelDraw Outbound» — запрос из плагина
  (он внутри CorelDRW.exe) не проходит (SocketException, доступ запрещён). Поэтому `HttpLicenseApi`
  при неудаче прямого запроса идёт через `Strassio.Connect.exe` рядом с аддоном (отдельный процесс,
  net48, только https/localhost; stdin — тело, stdout — «код
тело» или «ERR …»). Получилось —
  дальше сразу через него. Причина неудачи показывается в окне «Лицензия».

### 13.4 Переустановка и перенос (самообслуживание, как у rStones)
- **Переустановка Windows:** код компьютера тот же → на сайте тот же ключ и код → новый код активации.
  Не считается переносом.
- **Новый компьютер:** на сайте ключ + код нового ПК → сервер видит, что место занято → сайт предлагает
  «Перенести на этот компьютер». Старая активация отзывается и отключится при следующей проверке.
- Переносов сколько угодно, но не чаще **раза в 7 дней** (решение автора, 22.09.2026; было 3 за 365 дней).
  Раньше — через автора в Telegram (кнопка «разрешить перенос сейчас» в админке снимает ожидание).
  «Освободить» на сайте (/license) тоже считается переносом.
- **Один ключ — один компьютер** (решение автора, 22.09.2026). Число компьютеров в админке не меняется.

### 13.5 Пробная версия
- 14 дней, выдаётся сервером, привязана к коду компьютера (переустановка не сбрасывает).
- После окончания: кнопки создания неактивны, настройки и таблица камней доступны.

### 13.6 Админка (генератор ключей)
Веб-страница на сервере, вход по паролю:
- создать один или пачку ключей (срок, число ПК, заметка: имя клиента, Telegram);
- поиск, список активаций по ключу, версии плагина/CorelDRAW;
- отозвать активацию, сбросить счётчик переносов, продлить, заблокировать;
- **офлайн-активация:** вставить код компьютера клиента → получить файл лицензии (для клиентов без интернета);
- журнал действий.

### 13.7 Защита кода
- Обфускация сборок (бесплатные: Obfuscar или форк ConfuserEx) — на этапе 6.
- Стопроцентной защиты не бывает; цель — чтобы купить было проще, чем искать взлом.
- Что остаётся возможным без обфускации: исправить саму DLL (dnSpy) так, чтобы проверка всегда
  говорила «можно». Проверка стоит в трёх местах докера и в создании кругов; обфускация
  (Obfuscar) — следующий шаг, до начала продаж.
- Пока сервер не запущен в интернете, проверка выключена сборочным свойством
  `StrassioEnforceLicense` (Strassio.Corel.csproj); окно «Лицензия» при этом работает.

## 14. Обновления и установщик

### 14.1 Проверка обновлений
- `GET /api/update/latest?channel=stable` → `{version, url, sha256, notesRu, notesEn, minVersion}`,
  ответ подписан тем же ключом, что и лицензии.
- При запуске и раз в сутки (если в настройках включено «Проверять обновления», по умолчанию — да) плагин
  спрашивает сервер; версия новее установленной — строка в докере «Доступна новая версия X» (ссылка).
  Подпись ответа проверяется, ссылка — только https (`UpdateChecker`, тесты `UpdateCheckerTests`).
  `minVersion` выше установленной — строка «Эта версия устарела — обновитесь».
- Нажатие → окно «что нового» на текущем языке. Без SHA-256 в ответе — «Скачать?» → ссылка в браузере.
- **Автообновление** (просьба автора 2026-11-06). Есть SHA-256 → «Обновить само?»: «Да» — плагин
  копирует `Strassio.Connect.exe` в `%LOCALAPPDATA%\Strassio\updates\helper\` и запускает
  `UPDATE <url> <sha256> <версия> <папка>`. Программа обновления (отдельный процесс — брандмауэр
  CorelDRAW её не касается, файл без «метки интернета») скачивает установщик, сверяет SHA-256 из
  подписанного ответа, ждёт, пока закроют все `CorelDRW.exe` (до 7 дней), сверяет ещё раз и запускает
  установщик `/SILENT /SP- /NORESTART` (одно окно UAC). Непроверенный файл не запускается никогда.
  Ход — в `updates\status.txt` (скачивается / ждёт CorelDRAW / ставится / не получилось), докер
  показывает его строкой. После установки первый запуск говорит «Strassio обновлён до X» и убирает
  скачанное. «Нет» — страница загрузки в браузере, как раньше. Логика — `AutoUpdate` (общий файл для
  `Strassio.Licensing` и `Strassio.Connect`), тесты `AutoUpdateTests`.
- Каналы: stable / beta (бета — для тестеров). Плагин спрашивает stable.
- Установщики — на GitHub Releases публичного репозитория `little-7o7/strassio-releases` (код Strassio
  закрыт с 2026-11-06). Постоянная ссылка на последнюю версию: `<сайт>/download`.

### 14.2 Установщик (Inno Setup)
- Находит все установленные версии CorelDRAW (X7+), 32 и 64 бит, предлагает галочки.
- Копирует аддон в `Addons\Strassio\` каждой выбранной версии; файлы не «блокируются» Windows.
- Ждёт закрытия `CorelDRW.exe`, если он запущен. При `/SUPPRESSMSGBOXES` не зацикливается, а отменяет установку.
- Обновление поверх отмечает те же версии CorelDRAW, что и в прошлый раз (`HKLM\Software\Strassio\Target*`);
  ни одна прошлая не нашлась — отмечены все.
- Удаление через «Программы и компоненты» с сохранением пользовательских настроек в `%APPDATA%`.
- Цифровая подпись установщика (сертификат) — позже; без неё Windows SmartScreen может предупреждать.

## 15. Сервер

- **С 2026-11-06:** Vercel Pro (коммерческое использование разрешено; Hobby — только некоммерческое).
- Адрес сервера зашит в плагин — до первой продажи решить, остаётся ли strassio.vercel.app или свой домен.
- Логика в `server/core/` без привязки к платформе; `server/vercel/` — тонкий адаптер.
- База: Postgres (Neon) через `DATABASE_URL`.

### API
- `POST /api/activate` — ключ + hwid → файл лицензии или ошибка (занято → предложение переноса).
- `POST /api/transfer` — перенос на текущий компьютер.
- `POST /api/check` — периодическая проверка.
- `POST /api/deactivate` — освободить место (кнопка в плагине).
- `POST /api/trial` — пробная лицензия.
- `GET  /api/update/latest` — информация об обновлении.
- Ограничение частоты запросов на все эндпоинты.

### Таблицы
- `licenses` — ключ, план, статус, срок, число ПК, переносы (счётчик и дата сброса), заметка, даты.
- `activations` — лицензия, hwid, статус, первая активация, последняя проверка, версии плагина/CorelDRAW.
- `trials` — hwid, дата начала.
- `audit_log` — кто, что, когда.

## 18. Совместимость с CorelDRAW — решение по Этапу 0

Статус: **подтверждено автором на реальном CorelDRAW** (скриншот, панель «Strassio», докер,
кнопка создаёт круг ss6). Единая сборка interop (v20, `EmbedInteropTypes=true`) и формат XSLT
от bonus630 работают на версии CorelDRAW автора без доработок. Проверка на других версиях
(старых X7/X8 и самых новых) — по мере доступа к ним, при необходимости переходим на матрицу
MSBuild-конфигураций (план ниже остаётся в силе как запасной вариант).

### Одна DLL на все версии или матрица сборок
- Сейчас `Strassio.Corel` собирается против интеропа CorelDRAW 2018 (v20) с `EmbedInteropTypes=true`
  (см. `src/Strassio.Corel/interop/Corel.Interop.VGCore.dll` и комментарий в `.csproj`). Локально
  собирается без ошибок одним `dotnet build` на .NET SDK 9 (net48 + WPF, `PlatformTarget=AnyCPU`).
- Сам файл interop — собственность Corel, поэтому **в публичном репозитории его нет** (`.gitignore`).
  Копия хранится в закрытом репозитории автора `little-7o7/strassio-interop`. Без файла сборка
  `Strassio.Corel` останавливается с понятной ошибкой; ядро, тесты и Preview собираются и так.
- Найден реальный прецедент: открытый исходный код рабочего коммерческого аддона
  `bonus630/QrCodeDocker` (репозиторий на GitHub, поддерживает X7…2024+) **не использует одну общую
  сборку** — у него 19 конфигураций MSBuild (X7 Debug/Release, 2017…2024 Debug/Release), в каждой
  подключается свой `Corel.Interop.VGCore` под конкретную версию CorelDRAW. Это сигнал, что COM-интерфейс
  между версиями меняется достаточно, чтобы решение «одна встроенная сборка» было рискованным.
- План: сначала проверяем на машине автора, работает ли наша единая сборка (докер открывается,
  тестовая кнопка создаёт круг). Если где-то ломается — переходим на матрицу MSBuild-конфигураций
  по версиям, как у bonus630 (`Condition="'$(Configuration)|$(Platform)'=='2022 Release|AnyCPU'"`,
  `DefineConstants` с меткой версии). Один раз перейдём — опишем здесь новую схему.

### Формат кнопки, панели и докера (AppUI.xslt / UserUI.xslt)
- Формат не придуман, а построчно сверен с открытыми рабочими аддонами bonus630 для X7+:
  `DockerTemplateX7` (официальный VS-шаблон докера), `Bonus630DevToolsBar` и `QrCodeDocker`
  (оба — production-аддоны с собственной панелью инструментов).
- Схема, которую используем: `itemData type="wpfhost"` напрямую создаёт наш `UserControl`
  (`Docker` в `Strassio.Corel.dll`) и передаёт в конструктор `object app` — отдельная COM-регистрация
  или `IAddon`-интерфейс не нужны. Кнопка — `itemData type="checkButton"` с `check="*Docker('<guid>')"`.
  Панель инструментов — `commandBarData type="toolbar"`, пристыкована под стандартными панелями через
  тот же XPath-якорь (`dockHost` guid `894bf987-...` / `toolbar` guid `c2b44f69-...`), что использует
  сам bonus630 в проверенных аддонах.
- Пункт в меню «Окно → Докеры → Strassio» добавлен в `UserUI.xslt` через `commandBarData` guid
  `cdb9ea9c-223e-4865-97a6-31c007c69674` — тоже взят из рабочего примера, не проверен нами вживую.
- Значок камня (`assets/icon`) в кнопку пока **не встроен** — у CorelDRAW иконки для `itemData`
  подключаются через скомпилированный ресурс (`resources.rct`/`resources.dll`, связка `config.xml` +
  guid), это отдельная небольшая задача с нативной тулу (rc.exe/ResourceLib). Пока кнопка показывается
  только с подписью «Strassio», без картинки — добавим значок отдельным шагом после того, как
  заработает сама кнопка и докер.

### Тема докера как у CorelDRAW (Этап 2)
- Схему CorelDRAW читаем через `app.GetApplicationPreferenceValue("WindowScheme", "Colors")` — значение
  оканчивается на `LightestGrey`, `MediumGrey`, `DarkGrey` или `Black`. Смену ловим событием
  `app.OnApplicationEvent` с именем `OnColorSchemeChanged` (и `WorkspaceChanged`). Способ сверен
  с официальным шаблоном докера bonus630 `DockerTemplateX7` (`StylesController.cs`), который делает
  именно так; в X7 этой настройки нет — там берём тему Windows.
- CorelDRAW 2026 (v27) пишет новое значение `Scheme_11_ModernUI` (реестр:
  `HKCU\Software\Corel\CorelDRAW\27.0\Draw\Application Preferences\WindowScheme`, `Colors`) —
  для него своя светлая палитра `ModernUI`. Незнакомое имя со словом Dark/Black → тёмная палитра,
  иначе — тема Windows.
- Палитры — `Strassio.Core.Settings.ThemePalette`, применение — `Strassio.Corel.Themes.ThemeManager`,
  шаблоны элементов — `Strassio.Corel/Themes/Styles.xaml` (свои, стандартные Windows-шаблоны
  не красятся в тёмный цвет).

### Что нужно от автора
Собрать `Strassio.Corel` в Visual Studio (или `dotnet build`), скопировать содержимое
`src/Strassio.Corel/bin/Debug/net48/` в `Addons\Strassio\` (32- или 64-битная папка CorelDRAW —
смотря какая версия установлена) и открыть CorelDRAW. Подробный пошаговый список — в чате с Claude
после каждого такого шага.
