# Как поставить Strassio

Strassio работает в CorelDRAW на Windows. Цель — CorelDRAW X7 и новее (32 и 64 бита);
проверено на CorelDRAW 2025 и 2026.

## Установка

1. Закройте CorelDRAW.
2. Скачайте установщик последней версии: **https://strassio.vercel.app/download**
   (все версии — на странице [strassio-releases](https://github.com/little-7o7/strassio-releases/releases)).
3. Запустите `Strassio-Setup-<версия>.exe`. Он сам найдёт все CorelDRAW на компьютере и покажет
   их списком с галочками — снимите галочки с тех версий, куда ставить не нужно.
4. «Установить» → «Готово». Запустите CorelDRAW: вверху появится панель **Strassio** с кнопкой-камнем.
   Если панели нет — меню **Окно → Докеры → Strassio**.

Windows может предупредить «Неизвестный издатель» (у установщика пока нет цифровой подписи) —
нажмите «Подробнее» → «Выполнить в любом случае».

## Пробный период и активация

- **14 дней бесплатно.** Докер → шестерёнка (настройки) → «Лицензия…» → «Пробный период 14 дней».
  Пробный период один на компьютер, переустановка Windows его не сбрасывает.
- **Купили ключ** (`STRS-XXXX-XXXX-XXXX`): в том же окне «Лицензия…» нажмите «Открыть сайт активации» —
  код компьютера подставится сам. На сайте введите ключ и почту, скопируйте код активации,
  вставьте его в окно «Лицензия» и нажмите «Активировать».
- Один ключ — один компьютер. Перенос на новый компьютер — на сайте, на странице «Активация».

## Обновление

Плагин сам узнаёт о новой версии: под заголовком докера появится строка
«Доступна новая версия Strassio X». Нажмите её → «Да» — откроется загрузка установщика.
Закройте CorelDRAW и запустите установщик поверх старой версии: настройки, таблица камней
и лицензия сохранятся. Проверку можно выключить в настройках («Проверять обновления»).

## Удаление

«Параметры → Приложения» (или «Программы и компоненты»), либо ярлык «Удалить Strassio» в `C:\Strassio`.
Плагин убирается из всех версий CorelDRAW. Установщик спросит, сохранить ли настройки,
таблицу камней и лицензию: «Да» — после повторной установки всё будет на месте,
«Нет» — удалится всё.

Где лежат данные: `C:\Strassio\data` (настройки, таблица камней, пресеты, лицензия).

## Если что-то не так

Пришлите автору:
1. версию CorelDRAW;
2. скриншот;
3. текст из строки внизу докера (там плагин пишет, что получилось или какая вышла ошибка);
4. сведения из настроек → «О программе» → «Копировать».

## Для разработки

- Пересобрать установщик: `powershell -ExecutionPolicy Bypass -File installer\build-installer.ps1`
  (нужен бесплатный [Inno Setup 6](https://jrsoftware.org/isdl.php)). Обычно его собирает GitHub —
  см. [РАБОТА-НА-MAC.md](РАБОТА-НА-MAC.md).
- Быстрая переустановка без .exe, прямо из сборки:
  `powershell -ExecutionPolicy Bypass -File tools\install-addon.ps1` — от имени администратора,
  при закрытом CorelDRAW.
- CorelDRAW читает `AppUI.xslt` только при запуске, поэтому после каждой замены файлов
  его нужно перезапустить.
