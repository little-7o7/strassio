# Strassio 0.9.2 — порядок в докере, надёжность и работа без интернета
Если стоит 0.9.1 — нажмите в докере «Доступна новая версия» → «Обновить само?» → «Да», Strassio поставит
обновление, когда вы закроете CorelDRAW. Или закройте CorelDRAW и запустите **Strassio-Setup-0.9.2.exe** —
он встанет поверх прежней версии, настройки, таблица камней и лицензия сохранятся.

**Что нового**
- **Порядок в докере.** Вкладки стоят ровной сеткой 3×3 по шагам работы: «Векторы · Линия · Заливка», «Текст · Мотивы · Ткань», «Правка · Цвет · Шаблон».
- **Новая вкладка «Ткань»:** раппорт, лист без шва и камней на метр, россыпь и штрихи вокруг, обрезать по рамке (раньше было в «Мотивах»).
- **Новая вкладка «Шаблон»:** «Посчитать камни», перемычки, слои по размеру и цвету, подписи, чистые круги и сверление на станке (раньше было в «Правке»).
- **Сворачиваемые группы** внутри вкладок, как в докерах CorelDRAW. Докер помнит, какие группы открыты и на какой вкладке вы работали.
- Длинные подписи кнопок больше не обрезаются в узком докере.
- **Надёжность:** ошибка в Strassio больше не роняет CorelDRAW; если файл не записался, это видно сразу; лицензия не теряется из-за чужого ответа сети.
- **Сверление на станке:** проверка файла без ложных отказов, после смены сверла (M6) фреза поднимается.
- **Работа без интернета:** продление ключа подтягивается само при первой связи; годовой ключ предупреждает за 30 дней до конца, обычная лицензия без связи — за 4 дня до остановки.

If you have 0.9.1, click “New version available” → “Update automatically?” → “Yes” in the docker: Strassio
installs the update when you close CorelDRAW. Or close CorelDRAW and run **Strassio-Setup-0.9.2.exe**: it
installs over the previous version and keeps your settings, stone table and licence.

**What's new**
- **A tidy docker.** The tabs sit in an even 3×3 grid in the order you work: “Vectors · Line · Fill”, “Text · Motifs · Fabric”, “Edit · Colour · Template”.
- **New “Fabric” tab:** repeat, seamless sheet and stones per metre, splash and streaks around, trim to frame (moved from “Motifs”).
- **New “Template” tab:** “Count stones”, bridges, layers by size and colour, labels, clean circles and CNC drilling (moved from “Edit”).
- **Collapsible groups** inside the tabs, like in CorelDRAW's own dockers. The docker remembers which groups are open and which tab you used last.
- Long button captions are no longer cut off in a narrow docker.
- **Reliability:** an error in Strassio no longer crashes CorelDRAW; a file that failed to save is reported at once; a foreign network reply can no longer cost you your licence.
- **CNC drilling:** the file self-check no longer rejects good files, and the cutter lifts after a tool change (M6).
- **Working offline:** a renewed key is picked up by itself the next time the computer is online; a yearly key warns 30 days before it ends, a normal licence without a connection warns 4 days before it stops.
